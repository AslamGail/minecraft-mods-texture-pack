# Minecraft Mods & Texture pack

Static website for GitHub Pages. The deployment workflow publishes `index.html` and `favicon.svg` whenever changes are pushed to `main`.

## Publish

1. Create a GitHub repository and upload the files in this folder.
2. In the repository settings, open **Pages** and select **GitHub Actions** as the publishing source.
3. Push to `main`. GitHub Actions will publish the site and show its URL in the workflow run.
